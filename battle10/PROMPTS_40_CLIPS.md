# 10-MINUTE ANIME BATTLE - 40 CLIPS x 15 s (original characters: KAI vs MORO)

Made for **Triverse Studio > Video** (prompt limit 800 chars, 480P, 15 s = 75 credits per clip). Every prompt below is already under 800 characters and self-contained: style + setting + characters + scene.

## Credits
- 480P / 15 s = **75 credits** per clip -> all 40 clips = **3,000 credits**.
- You have **1,030 credits** -> **13 clips (0:00-3:15)** now. Do clips in order, 1 to 13, then continue when you top up.
- Credits are shared with 3D tasks on the same account, so don't spend them on 3D in between.

## How to chain clips (so KAI and MORO do not change look)
1. Clip 1: first, make a start image in Triverse **Image** with the *Start image prompt* below (or any image of this design).
2. Open Video > **Image** tab, load the start image as *First Frame*, paste the clip prompt, 480P, **15S**, Sound Effects **off**, Generate.
3. For clip N+1: save the **last frame** of clip N (screenshot / export) and use it as the *First Frame*. Optional: use *Add End Frame* when a scene must end in a known pose.
4. Name every download `clip_01.mp4` ... `clip_40.mp4`. If a clip drifts (wrong hair/costume), regenerate only that clip.
