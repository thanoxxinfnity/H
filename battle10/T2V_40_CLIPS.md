# 10-MINUTE ANIME BATTLE - TEXT-TO-VIDEO - 40 CLIPS x 15 s (original: ARAN vs VORTH)

For **Triverse Studio > Video > Prompt** tab (text-to-video, no first frame). Every prompt is self-contained (style + setting + character descriptions + scene) and under 800 characters. The story ends with ARAN's death; nothing is shown after it.

## Credits
- 480P / 15 s = **75 credits** per clip (check the Generate button, text-to-video may differ). All 40 clips = **3,000 credits**; with 1,030 credits do clips **1-13 (0:00-3:15)** first, in order.
- Credits are shared with 3D tasks on the same account.

## Tips for text-to-video
1. Paste the prompt exactly as written. The character descriptions at the start of each prompt must stay identical, that is what keeps ARAN and VORTH looking the same from clip to clip.
2. Settings: Prompt tab, 480P, 15S, Sound Effects **off**.
3. Text-to-video has no first frame, so the look can drift a little between clips. If a clip comes out wrong (wrong hair or coat colour), just regenerate that one clip with the same prompt.
4. For better continuity use the **Image** tab (see `PROMPTS_40_CLIPS.md`) and chain last frames; use this pack when you want to start every clip fresh.
5. Download as `t2v_clip_01.mp4` ... `t2v_clip_40.mp4` and send them; I will merge, add the AI disclaimer intro, and upscale.
